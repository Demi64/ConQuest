# ComQuest

MMOのクエストログの構造を、見た目ではなく**使い勝手の構造として**採り入れたタスク管理ツール。LLM（Claude）が入力の整理とフォローアップを担う前提で作っている。

- やることを「クエスト」（完了条件と経緯を持つ仕事の単位）に束ね、次の一手（現在の目的）を常に見えるようにする
- 入力はそのまま書く・話すだけ。クエスト化、タスクの分解、予定との紐づけはAIが行う
- AIは「やる／やらない／止まっている」を提案する。反映するかは自分で決める
- **クエストを完了にするのは人だけ**。AIにもシステムにも完了操作はない
- AIの書き込みは全て履歴に残り、取り消せる
- XP・レベル・報酬などのゲーミフィケーションは入れない

名前は Conquest（困難を成し遂げる）のもじり。「Quest を Complete する」「Computer と進める Quest」の意味も込めている。

## 状態

作者が自分で使うための小規模なOSSとして開発中（MVP）。自分の Cloudflare アカウントに置いて使う。利用者は1人を想定。

## 構成

Cloudflare Workers（TypeScript）＋ D1。画面はPWA。Claude とは MCP（リモートMCPサーバー、OAuth）でつなぐ。
